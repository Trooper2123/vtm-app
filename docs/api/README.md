# API

O contrato endpoint a endpoint está em [openapi.yaml](./openapi.yaml). Os fluxos ponta a ponta e seus passos de validação ficam em [flows](./flows/).

Ao criar ou alterar um endpoint, atualize o contrato e o fluxo correspondente no mesmo PR. Documente autenticação, permissões, validações, alterações de dados e respostas de erro.
